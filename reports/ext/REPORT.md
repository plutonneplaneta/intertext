# Проверка протокола на других материалах: итоги

Предрегистрация: `prereg_protocol_transfer.md` (коммит 068da1b). Критерии не менялись; исправления
собственного кода — в `deviations.md`. Воспроизведение: `scripts/ext/fetch_ext.sh`, затем `scripts/ext/run_ext_all.sh`
(минуты на счёт; основная работа — материал и эталон). Все ключевые числа сверены вторым прогоном (шаг 7).

Материалы: **A** — Мильтон, «Потерянный рай» → KJV (393 записи v0, 156 абзацев; эталон — примечания Лаксона);
**B** — тот же текст → Вергилий, Гомер, Овидий в переводах, единица — книга (98 записей, 58 абзацев).
Скореры написаны заново и простые (BM25, idf-косинус, символьные 4-граммы, «серия», слияние); ничего не перенесено.

## 3. Гипотезы о методологии

| | исход |
|---|---|
| M1 шаг 2 находит дефекты на обоих | подтверждено (на B только ручной выборкой) |
| M2 мостик/потолок | подтверждено (35,6% и 52,7% без мостика) |
| M3 длина не слабее лучшего скорера | подтверждено на обоих |
| M4 одиночные отличаются от всех ≥10% (A) | **не подтверждено** (6,6%); критерий разбавлен долей одиночных (64%), следует сравнивать группы между собой |
| M5 плацебо ≈ случайность | **не подтверждено** на обоих: плацебо сдвинуто (хабы, тематическая близость внутри книги, «популярность» цитируемых источников); осмысленная метрика — разность с плацебо, а не с случайностью |
| M6 фильтры 2, 3, 4 коммутируют | **не подтверждено на A**: 4 разных итоговых множества, n 144–147, размах среднего log-rank 0,08 (поправка меняет диапазон и мостик записи); на B коммутируют. Поправки эталона обязаны идти первыми |
| M7 избыточность | шаги 4 и 5 «дефекта нет» на обоих новых материалах, но дефекты были на исходном; решение — оставить, с условиями применимости (шаг 4: сравнивать группы; шаг 5: обязателен, когда записей на объект > 1). Пункты шага 6 про LLM неприменимы к методу без LLM |
| M8 независимый исполнитель | шаг 2: доли совпали (65/35/0), запись в запись 80%, каппа 0,56; шаг 3: **не воспроизведён** (49 против 23 без мостика, допуск ±3), текст протокола не задаёт порогов. См. `independent/COMPARISON.md` |

Время: счёт скореров 15–20 с на материал; подготовка материала и эталона заняла основную часть работы (оценка, не измерение).
Исполнитель оценил свои шаги 2–3 примерно в 1,5–2 часа.

## 4. Находки о тексте протокола (учтены в PROTOCOL.md 0.2)

1. «Ненулевой балл» как потолок вырожден для мешков слов: нужен потолок по рангу.
2. «Редкая лемма» и «два слова подряд» не определены; знаменатель шага 3 меняется вдвое (независимый исполнитель).
3. Шаг 4 про «одиночные против диапазонов» не переносится на крупные единицы источника; критерий «одиночные против всех» разбавлен.
4. Плацебо надо сравнивать с плацебо, а не со случайностью; хабы обязательны к проверке.
5. Ссылка в эталоне-комментарии часто даёт контекст, а не источник строки (25–35%): знаменатель полноты шага 3 это не решает.
6. Порядок: поправки эталона первыми.
7. Шаг 7 нужно дополнить: точность кэша, детерминизм при смене семени хеша, громкие фильтры.
8. Дефект источника (по независимому исполнителю): Iliad.24 раздут примечаниями Поупа; у меня он стал хабом BM25 (62% абзацев) — возможно, именно из-за этого. Не перепроверено после очистки, поэтому причина хаба — гипотеза.

## 5. Можно ли писать «универсальный»

Условия §6: два новых материала — да, но они делят целевой текст и составителя эталона; дефекты на ≥2 шагах каждого — да; критерии не менялись — да;
шаг независимым исполнителем — выполнен, но шаг 3 не воспроизведён; ограничения — ниже.
По собственной оговорке предрегистрации слово «универсальный» **не используется**. Формулировка: «протокол выведен из кейса (Достоевский —
Синодальная Библия) и проверен на двух материалах (Мильтон — KJV, Мильтон — классики в переводах), английский язык, эталон — научные
примечания одного составителя, только лексические скореры, 93–390 записей».

Ограничения: один целевой текст и один составитель для новых материалов; нет материала на другом языке с морфологией и нет тематических связей
без лексики, кроме B; нет LLM, поэтому шаг 6 проверен лишь частично; ручная разметка — одним человеком (сам автор), независимая — только на B;
выборки мелкие (35 записей на множестве протокола в B), поэтому «не подтверждено» ≠ «опровергнуто».
